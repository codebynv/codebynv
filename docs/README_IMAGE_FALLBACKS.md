# README Image Fallbacks

External images and statistics cards can become unavailable.

- Use meaningful alt text.
- Link cards to the relevant profile or repository where useful.
- Avoid relying on a single third-party endpoint for critical information.
- Prefer simple text links when an image service is unreliable.
- Recheck rendered images after updating their URLs.

Third-party cards may cache results, so source changes may not appear immediately.
