# Project Description Template

Use this outline when documenting a featured project.

## Problem
What practical need does the project address?

## Solution
What does the implementation actually do?

## Technology
List the primary technologies used.

## Verification
Describe tests, a working demo, or repeatable manual checks.

## Limitations
State important constraints or unfinished areas honestly.

Prefer specific evidence over broad claims such as “production-ready” unless that status is demonstrated.
