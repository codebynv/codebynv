# Profile Release Checklist

Before updating the profile README:

- [ ] Confirm all links use the intended destination.
- [ ] Check image URLs and fallback behavior.
- [ ] Verify featured project names and descriptions.
- [ ] Remove stale or broken badges.
- [ ] Preview Markdown rendering.
- [ ] Avoid publishing personal or credential data.

After committing, inspect the rendered profile to catch provider outages that a source review cannot detect.
