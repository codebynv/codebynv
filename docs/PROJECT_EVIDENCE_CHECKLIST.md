# Project Evidence Checklist

For each featured project, keep claims tied to verifiable evidence.

- Link to the actual repository.
- Describe implemented features accurately.
- Link a live demo only when it is available.
- Mention tests that were actually run.
- Distinguish completed work from planned work.
- Keep technology lists aligned with the codebase.

Avoid unsupported claims about users, performance, deployment, or production readiness.
