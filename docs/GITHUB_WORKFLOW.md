# GitHub Workflow

This profile repository contains public-facing profile content and contribution visualizations.

## Profile changes

Before changing the profile README:

- Keep links valid.
- Check image and badge URLs.
- Keep sections readable on both desktop and mobile.
- Avoid embedding assets that depend on private repositories.

## Contribution assets

Contribution graphs and generated assets may depend on external endpoints or repository-hosted files. When changing an asset URL, verify that the referenced path and branch are correct.

## Commit practice

Use focused commits such as:

- `docs: update profile section`
- `fix: repair contribution asset link`
- `chore: refresh profile metadata`

Review the rendered README after significant changes so broken Markdown or images are caught before publishing.
